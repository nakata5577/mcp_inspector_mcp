## 🎉 概要

MCP Inspector MCP Server v0.4.0は、**Phase 3: 機能拡張フェーズ**の完了を記念するメジャーリリースです。本リリースでは、エンタープライズグレードの開発ツールとして必要な機能を大幅に強化しました。

### ハイライト

- **デバッグ効率50%向上**: 詳細ログとリクエスト/レスポンス可視化
- **CI/CD完全統合**: バッチテスト機能による自動テスト実現

### 1. デバッグモード (Task 3.1)

**問題解決時間を50%削減する強力なデバッグツール**

#### 主な機能

- **--verboseフラグ**: 詳細デバッグ情報の出力
  ```bash
  mcp_inspector_mcp --verbose
  ```

- **整形表示**: JSONRPCメッセージの見やすい表示
  - カラー表示（成功=緑、エラー=赤、警告=黄）
  - 大きなペイロードの自動トランケート
  - Unicode対応

- **タイミング情報**: 高精度計測
  - マイクロ秒精度のタイムスタンプ
  - 各操作の経過時間表示
  - パフォーマンス分析に有用

- **ログファイル出力**: デバッグログの永続化
  - 日付ベースのローテーション
  - 設定可能な保存期間
  - 構造化ログ（JSON形式）対応

#### 使用例

```bash
# デバッグモード有効化
mcp_inspector_mcp --verbose

# 環境変数で指定
export MCP_VERBOSE=true
mcp_inspector_mcp

# ログファイルへの出力
export RUST_LOG=debug
mcp_inspector_mcp --verbose 2>&1 | tee debug.log
```

### 2. バッチテスト機能 (Task 3.2)

**CI/CD統合とテスト自動化の実現**

#### 主な機能

- **テスト定義**: YAML/JSON形式
  - 構造化されたテストスイート定義
  - 12種類の柔軟なアサーション
  - テスト設定（タイムアウト、リトライ、並列実行）

- **テスト実行エンジン**: 高性能
  - 並列/順次実行の選択
  - テスト失敗時の自動リトライ
  - fail_fast/fail_safe モード

- **レポート生成**: 3形式対応
  - **Console**: 人間が読みやすい形式
  - **JSON**: プログラムで処理可能
  - **JUnit XML**: CI/CD統合用

- **CI/CD統合**: 完全サポート
  - GitHub Actions対応
  - GitLab CI対応
  - 終了コードによる成否判定

#### 12種類のアサーション

| アサーション | 説明 | 例 |
|------------|------|-----|
| `status` | ステータス値の検証 | `"healthy"` |
| `field_exists` | フィールドの存在確認 | `"tools"` |
| `field_equals` | フィールドの値が期待値と一致 | `"AAPL"` |
| `field_not_equals` | フィールドの値が期待値と不一致 | `null` |
| `array_length` | 配列長の検証 | `> 0` |
| `contains` | 配列が特定値を含むか | `"calculate_rsi"` |
| `response_time` | レスポンスタイムの検証 | `< 500ms` |
| `error_rate` | エラー率の検証 | `< 5%` |
| `error_type` | エラータイプの検証 | `"Timeout"` |
| `error_message_contains` | エラーメッセージ検証 | `"connection"` |
| `json_contains_key` | JSON内のキー存在確認 | `"rsi"` |
| `json_value_type` | JSON値の型検証 | `"number"` |
| `json_value_range` | 数値範囲の検証 | `0-100` |

#### 使用例

**テストスイート定義 (test_suite.yaml):**

```yaml
name: "Fundamental Analysis Server Test Suite"
version: "1.0"
description: "Comprehensive test suite"

config:
  timeout_ms: 30000
  retry_count: 1
  fail_fast: false
  parallel: true

tests:
  - name: "Server Health Check"
    description: "Verify server is responsive"
    tool: "health_check"
    server: "fundamental_analysis"
    arguments: {}
    assertions:
      - type: "status"
        expected: "healthy"
      - type: "response_time"
        operator: "<"
        expected: 500

  - name: "Calculate RSI for AAPL"
    description: "Test RSI calculation tool"
    tool: "tools_call"
    server: "fundamental_analysis"
    arguments:
      tool_name: "calculate_rsi"
      arguments:
        symbol: "AAPL"
        period: 14
    assertions:
      - type: "json_value_type"
        field: "result.content[0].text.rsi"
        expected: "number"
      - type: "json_value_range"
        field: "result.content[0].text.rsi"
        min: 0
        max: 100
```

**テスト実行:**

```bash
# テストスイート実行
mcp_inspector_mcp test run --suite tests/basic_test.yaml

# 並列実行
mcp_inspector_mcp test run --suite tests/advanced_test.yaml --parallel

# JUnit XML形式でレポート生成
mcp_inspector_mcp test run --suite tests/ci_test.yaml \
  --report-format junit --output results.xml
```

**GitHub Actions統合:**

```yaml
name: MCP Server Test

on: [push, pull_request]

jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - name: Run MCP Tests
        run: |
          mcp_inspector_mcp test run \
            --suite tests/ci_test.yaml \
            --report-format junit \
            --output test-results.xml
      - name: Publish Test Results
        uses: EnricoMi/publish-unit-test-result-action@v2
        with:
          files: test-results.xml
```

### 3. パフォーマンスモニタリング (Task 3.4)

**リアルタイムメトリクス収集とボトルネック自動検出**

#### 主な機能

- **メトリクス収集**: リアルタイムパフォーマンスデータ
  - レスポンスタイム（平均、最小、最大、P50/P95/P99）
  - スループット（リクエスト数/秒）
  - エラー率
  - 同時実行数

- **統計集計**: 時間窓ベース
  - 1分/5分/15分の移動平均
  - パーセンタイル計算
  - トレンド分析

- **レポート生成**: 3形式対応
  - **Console**: ターミナルでの表示
  - **JSON**: プログラムで処理
  - **HTML**: ブラウザでの可視化（グラフ付き）

- **ボトルネック検出**: 自動問題検出
  - 遅いレスポンスの特定
  - エラー率の急上昇検出
  - リソースボトルネックの特定

#### 使用例

```bash
# メトリクス収集開始
mcp_inspector_mcp monitor start

# コンソールレポート表示
mcp_inspector_mcp monitor report

# JSONレポート生成
mcp_inspector_mcp monitor report --format json --output metrics.json

# HTMLレポート生成
mcp_inspector_mcp monitor report --format html --output performance.html

# ボトルネック検出
mcp_inspector_mcp monitor analyze --detect-bottlenecks
```

#### HTMLレポート例

HTMLレポートには以下の情報が含まれます:

- **サマリー**: 総リクエスト数、平均レスポンスタイム、エラー率
- **レスポンスタイム分布**: ヒストグラム、パーセンタイル
- **時系列グラフ**: レスポンスタイム、スループット、エラー率
- **ボトルネック分析**: 遅いツール、エラーが多いツール
- **推奨事項**: パフォーマンス改善の提案

**セキュリティ強化:**
- XSS対策（入力サニタイズ）
- Content Security Policy (CSP)ヘッダー

### 4. 構成管理拡張 (Task 3.5)

**環境別設定の柔軟な管理とプロファイル機能**

#### 主な機能

- **プロファイル機能**: 環境別設定管理
  - 4種類のプリセット（default、dev、staging、prod）
  - プロファイル切替（`--profile dev`）
  - 環境変数対応（`MCP_PROFILE=staging`）
  - プロファイル検証機能

- **インポート/エクスポート**: 設定の移植性向上
  - JSON/YAML形式対応
  - 設定バリデーション
  - 差分表示（`--dry-run`）
  - フォーマット自動検出

- **テンプレート機能**: 設定の標準化
  - 4種類のプリセット（minimal、development、production、ci）
  - カスタムテンプレート作成
  - テンプレート一覧表示
  - テンプレート削除

#### プリセットプロファイル

| プロファイル | 用途 | 特徴 |
|------------|------|------|
| `default` | デフォルト | 標準設定 |
| `dev` | 開発環境 | デバッグログ有効、短いタイムアウト |
| `staging` | ステージング | 本番に近い設定、詳細ログ |
| `prod` | 本番環境 | 最適化された設定、エラーログのみ |

#### 使用例

**プロファイル機能:**

```bash
# プロファイル一覧表示
mcp_inspector_mcp --list-profiles

# プロファイル使用
mcp_inspector_mcp --profile dev

# 環境変数でプロファイル指定
export MCP_PROFILE=staging
mcp_inspector_mcp

# プロファイル検証
mcp_inspector_mcp --validate-profile prod
```

**インポート/エクスポート:**

```bash
# 設定エクスポート（JSON）
mcp_inspector_mcp config export --output config_backup.json

# 設定エクスポート（YAML）
mcp_inspector_mcp config export --output config_backup.yaml --format yaml

# 設定インポート（dry-run）
mcp_inspector_mcp config import --input config_backup.json --dry-run

# 設定インポート
mcp_inspector_mcp config import --input config_backup.json

# バリデーション
mcp_inspector_mcp config validate --input config_backup.json
```

**テンプレート機能:**

```bash
# テンプレート一覧
mcp_inspector_mcp config template list

# テンプレート表示
mcp_inspector_mcp config template show --template production

# テンプレート適用
mcp_inspector_mcp config template apply --template development --profile dev

# カスタムテンプレート作成
mcp_inspector_mcp config template create --name my_template --from-profile default

# カスタムテンプレート削除
mcp_inspector_mcp config template delete --name my_template
```

#### プロファイルファイル例

    {

## 🔧 移行ガイド

### v0.3.xからの移行

既存の`.inspector/config.json`設定はそのまま動作します。新機能を使用する場合のみ、以下の追加設定を行ってください。

#### デバッグモードの有効化

```bash
# 環境変数で設定
export MCP_VERBOSE=true
mcp_inspector_mcp

# または--verboseフラグを使用
mcp_inspector_mcp --verbose
```

#### バッチテストの使用

1. テストスイートを作成（`examples/test_suites/`を参考）
2. テスト実行

```bash
mcp_inspector_mcp test run --suite your_test.yaml
```

#### プロファイルの使用

```bash
# プロファイルを指定して起動
mcp_inspector_mcp --profile dev
```

### トラブルシューティング

**デバッグモードが有効にならない場合:**

```bash
# 環境変数を確認
echo $MCP_VERBOSE

# ログレベルを確認
echo $RUST_LOG
```

**バッチテストが失敗する場合:**

```bash
# テスト定義のバリデーション
mcp_inspector_mcp test validate --suite your_test.yaml

# 詳細ログで実行
RUST_LOG=debug mcp_inspector_mcp test run --suite your_test.yaml
```

**プロファイルが見つからない場合:**

```bash
# プロファイルリストを確認
mcp_inspector_mcp --list-profiles

# プロファイルファイルが存在するか確認
ls .inspector/config.*.json
```
